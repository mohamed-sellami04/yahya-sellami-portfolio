# Personal images

The profile portrait is `profile.jpg` and is configured in `src/data/portfolio.js`. Replace it with another portrait here and update `profile.photo` if you use a different filename.

Place BlueBox overview images in `public/images/bluebox/` and list them in `bluebox.screenshots`. Project flow diagrams live in `public/images/bluebox/architecture/` and use `bluebox.architectureDiagrams`. Mobile app screenshots live in `public/images/bluebox/mobile/` (the existing irrigation schedule image can be reused from the overview gallery) and use `bluebox.mobileScreenshots`. Embedded controller screenshots live in `public/images/bluebox/embedded/` and use `bluebox.embeddedScreenshots`. Use genuine product screenshots. No fabricated product images are included.

Recommended sizes: portrait 800 × 1000 px; screenshots 1600 px wide. WebP or compressed JPEG is suitable. Always provide meaningful alt text.
